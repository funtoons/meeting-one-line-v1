# The Meeting That Should Have Been One Line

Entry for the [make.fun bounty](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c): one sentence that could have replaced an entire pointless meeting.

`main.py` (stdlib only, deterministic, offline) writes a single 124-character line to `/output/entry.txt`:

> I read the 12-page pre-read, attended the 60-minute meeting, and learned the decision was made in the hallway in 40 seconds.

Run: `python3 main.py` (or `OUTPUT_DIR=/tmp/out python3 main.py`).
